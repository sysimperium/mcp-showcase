As 3 Primitivas Fundamentais

Como os agentes inteligentes utilizam o protocolo para executar ações e contextualizar respostas.

🛠️

Tools (Ferramentas)

Funções executáveis com esquema JSON rígido que os modelos chamam dinamicamente para interagir com o mundo real (ex: disparar deploys, consultar APIs ou rodar queries).

📦

Resources (Recursos)

Dados contextuais passivos que os modelos podem ler como referências seguras, tais como arquivos de configuração, esquemas de bancos de dados ou logs.

💬

Prompts

Modelos de comandos pré-estruturados e fluxos guiados que facilitam tarefas recorrentes diretamente integradas no cliente de IA.
